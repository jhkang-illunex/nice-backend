# CRI 계산 로직 해설 (cri_spec.md 코드)

> 첨부 코드(`docs/cri_spec.md`)에서 직관적이지 않은 부분을 짚어 설명한다. 신용위험지표(CRI)는
> "거래상대방들의 신용등급을 거래비중으로 가중평균"한 값이며, **직접 거래뿐 아니라 다단계
> 간접 거래(loop 포함)까지 누적**한다는 게 핵심이다. 모든 수치는 코드 실행으로 검증함.

---

## 1. 입력 데이터

| 변수 | 의미 |
|---|---|
| `grades` | 기업별 신용등급 (AAA~D, `NR`=무등급) |
| `score` | 등급→점수 (AAA=1 … D=10). **숫자가 클수록 위험**. NR/R은 매핑에 없음(=제외) |
| `sales` | 기업별 매출액 (Network Risk Index 가중에만 사용) |
| `edges` | `(source, target, sell_share, buy_share)` — source가 target에게 **판매** |

**두 비중의 정의 (주의 — 둘 다 분모가 "매출"):**
- `sell_share` = 거래액 / **셀러(source) 매출** = source가 자기 매출 중 target에 판 비율.
- `buy_share` = 거래액 / **바이어(target) 매출** = (스펙 정의 그대로) target 매출 대비 source로부터 산 비율.
  → 구매비중인데도 분모가 바이어의 *매입*이 아니라 *매출*임에 유의(스펙 정의). 샘플로 확인:
  `A→B` 거래액=300(=0.3×A매출1000), buy_share=0.375=300/800(B매출). ✓

## 2. `propagate()` — 핵심: 다단계 누적 거래망 (등비급수)

가장 설명이 필요한 함수. **두 노드 사이의 "직접+간접 거래 익스포저"를 전부 합산**한다.

```
T = W + λW² + λ²W³ + …        (W=직접거래 행렬, λ=단계별 감쇠)
```
`total[(src,dst)]` = src에서 dst로 가는 **모든 경로**(길이 1,2,3,…, loop 포함)의 가중치 곱의 합.

### 동작 방식 (edge-list로 행렬곱 없이)
1. `current` = **1단계(직접) 거래** W. (`A→B 0.3`, `A→D 0.2`, …)
2. 매 step:
   - `total += current` (이번 길이의 경로 누적)
   - `current` = `current × graph` → **한 홉 더 간** 경로. (`A→B`와 `B→C`를 이으면 `A→C 0.3×0.5`)
   - `× λ` 로 단계 감쇠 (기본 λ=1.0 → 감쇠 없음)
3. `current`의 총합 < epsilon 이면 종료. (샘플은 17단계서 수렴)

### 왜 중요한가 — 간접 익스포저
A는 C와 **직접 거래가 없지만**, `A→B→C` 경로로 C에 간접 노출된다.
`propagate`가 이걸 `total[(A,C)]`=0.193966 으로 잡아준다. 즉 CRI는 "1차 거래처"가 아니라
**거래망 전체로 퍼진 신용 노출**을 본다.

### loop / self-return
`A→B→A`, `A→D→B→A` 같은 순환이 있으면 `total[(A,A)]`(자기 자신으로 복귀)가 생긴다(샘플 0.0776).
- **전파 계산엔 포함**(거래망 구조상 실제로 도는 비중이라).
- **단, 최종 CRI에선 제외**(자기 등급이 섞이면 안 되므로 — §3에서 `dst==i` 차단).

> 우리 shock 전파 엔진(`nice_shock`)의 `Σₖ Rᵏ·init`과 **수학적으로 동일 구조**다. 차이는 CRI는
> 시드 주입 없이 "모든 (src,dst) 쌍의 누적 거래비중 행렬"을 통째로 구한다는 점뿐.

## 3. `calc_company_index()` — 기업별 지표

각 기업 i에 대해, i가 출발(src=i)인 누적경로만 모아 계산한다.

| 출력 | 식 | 의미 |
|---|---|---|
| **전체누적비중** | Σ w (단, `dst≠i`) | i가 거래망 전체로 가진 누적 거래비중(self 제외) |
| **유효누적비중** | Σ w (단, `dst≠i` **AND** dst가 유효등급) | 그중 **등급 있는** 거래처 몫만 |
| **Coverage** | 유효 / 전체 | "내 거래 노출 중 등급으로 평가 가능한 비율" |
| **가중평균CRI** | Σ(w·score) / 유효누적비중 | 등급 거래처들의 **거래비중 가중평균 등급점수** |
| **CRI Exposure** | Σ(w·score) | 나누지 않은 분자(절대 위험노출량) |

**제외 규칙 두 가지 (전파엔 포함, CRI 계산서만 제외):**
- `dst == i` (self-return) → skip.
- `grades[dst]` 가 NR/R (score에 없음) → 분자·유효비중에서 제외(단, **전체누적비중엔 포함**).

### 검증된 예 — A의 판매망 (실행 확인)
```
A→A 0.077586  AA  → self-return, CRI 제외
A→B 0.387931  NR  → 무등급, 유효 제외 (전체엔 포함)
A→C 0.193966  BBB(4)
A→D 0.215517  A(3)
A→E 0.086207  BB(5)

전체누적비중 = 0.387931+0.193966+0.215517+0.086207 = 0.883621
유효누적비중 = 0.193966+0.215517+0.086207           = 0.495690   (B=NR 빠짐)
Coverage    = 0.495690 / 0.883621 = 0.560976
가중평균CRI = (0.193966·4 + 0.215517·3 + 0.086207·5) / 0.495690 = 3.739130
CRI Exposure= 1.853448
```
→ 스펙 출력표(A행)와 정확히 일치.

### "-"(C, E 판매망) 가 나오는 이유
C·E는 **판매(outgoing) 엣지가 없다** → 전체누적비중=0 → 나눌 게 없어 avg_cri=None("-").
(구매망에선 반대로 구매 엣지 없는 기업이 "-"가 됨.)

## 4. `calc_network_index()` — 네트워크 전체 지표

기업별 지표를 **매출액 가중**으로 합쳐 망 전체 평균을 낸다.

```
Network Risk Index = Σ_i (매출_i · Exposure_i) / Σ_i (매출_i · 유효누적비중_i)
Network Coverage   = Σ_i (매출_i · 유효누적비중_i) / Σ_i (매출_i · 전체누적비중_i)
```
- 분자: 매출 큰 기업의 위험노출에 더 큰 비중.
- 분모: 매출 가중 유효비중. → 결과는 "망 전체의, 유효 거래망 기준 평균 거래상대 CRI 수준".
- 판매망 3.784 / 구매망 2.393 → 구매망 거래처들이 평균적으로 더 우량(점수 낮음).

## 5. 해석 시 헷갈리기 쉬운 포인트 요약

| 포인트 | 설명 |
|---|---|
| 점수 방향 | **클수록 위험**(AAA=1, D=10). "가중평균CRI 3.7"=평균 A~BBB 수준 |
| 전체 vs 유효 | 전체=모든 누적거래(무등급 포함), 유효=등급기업만. **Coverage가 신뢰도** |
| NR/R | 전파·전체비중엔 포함, CRI 점수 계산만 제외 |
| self-return | loop로 자기복귀한 비중. 전파 포함, CRI 제외 |
| 간접 거래 | 직접 거래 없어도 다단계 경로로 노출 잡힘(A→C via B) |
| sell/buy_share 분모 | **둘 다 매출(Σ_out)** 기준 (buy도 바이어 매입이 아닌 매출 기준 — 스펙 정의) |
| λ(lamb) | 단계 감쇠. 기본 1.0=무감쇠. 발산 우려 시 <1로 (ρ<1 보장) |

## 6. DB-독립(stateless) 실행에 필요한 입력 (참고)

이 로직을 DB 없이 돌리려면 — shock-server의 `triple_list` 패턴과 동일:
- **노드**: `{id, grade(또는 score), sales}`
- **엣지**: `{source, target, sell_share, buy_share}`

`score` 매핑·노치제거·λ는 엔진 내부 상수. DB 정규화(amt/Σ_out)와 등급 노치제거는 입력 조립
단계에서 끝내고 엔진엔 이미-정규화된 값만 넘긴다.

---

기호: W=직접거래 가중치 행렬, T=누적거래 행렬, λ=lambda(단계 감쇠율), Σ=합, ρ=rho(spectral radius), Σ_out=총매출
