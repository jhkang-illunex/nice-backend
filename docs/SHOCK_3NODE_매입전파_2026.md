# 3노드 매입(upstream) 충격 전파 풀이 — 2026, 포스코 충격 0.1

> 외생충격(tariff)과 거래량변동(volume) 모두 **포스코에 충격 0.1**을 주입해 **매입 에지**를
> 따라 전파하는 과정. 거래연도 2026, 파생 depth=1, 3노드 그래프.
> **거래비율은 각 노드의 연간 전체 거래량(모든 거래처) 기준으로 정규화** — 3노드 안으로
> 한정하지 않음(= 데모 `within_subgraph=False`, canonical trade_rate). 엔진(`nice_shock`) 검증.

대상 3개 회사:

| 약칭 | 회사 | bizno |
|---|---|---|
| P | (주)포스코 | 3018702315 |
| G | 주식회사 지오테크놀로지 | 1318636602 |
| H | 주식회사 합동씨티에스 | 6098602207 |

## 1. 그래프 — 2026 거래액 + 연간 전체 총매입

**3노드 사이 거래액 (2026):**

| 거래 (셀러→바이어) | 거래액(원) |
|---|---|
| G → P | 107,756,591 |
| P → G | 107,756,591 |
| H → P | 1,092,315,642 |
| P → H | 1,092,315,642 |

**각 회사의 연간 전체 총매입 Σ_in (3노드 밖 거래처까지 전부):**

| 회사 | 연간 Σ_in(2026) | 비고 |
|---|---|---|
| P (포스코) | **1,800,180,187** | 3노드(G·H)에서 12억, 나머지 6억은 **다른 공급사** |
| G (지오) | **934,580,732** | 포스코 거래(1.08억)는 그 일부 |
| H (합동) | **1,197,376,560** | 포스코 거래(10.9억)가 대부분 |

> ★ 핵심: 분모를 "3노드 내 합"이 아니라 **연간 전체 Σ_in**으로 쓴다. 그래서 G·H 가 포스코로
> 되돌리는 비율도 1.0 이 아니라(자기들도 다른 데서 매입하니까) 1 미만이 된다.

---

## 2. 매입(upstream) 에지 — 방향·정규화

매입 파급은 **바이어→셀러** 방향. 가중치 = **매입비중** = `거래액 / 바이어의 연간 전체 Σ_in`.

| 매입 에지 (바이어→셀러) | 원거래 / 연간 Σ_in(바이어) | rate | 의미 |
|---|---|---|---|
| P → G | 107,756,591 / 1,800,180,187 | **0.0599** | 포스코 매입 중 지오 비중 |
| P → H | 1,092,315,642 / 1,800,180,187 | **0.6068** | 포스코 매입 중 합동 비중 |
| G → P | 107,756,591 / 934,580,732 | **0.1153** | 지오 매입 중 포스코 비중 |
| H → P | 1,092,315,642 / 1,197,376,560 | **0.9123** | 합동 매입 중 포스코 비중 |

```
         0.0599
     ┌──────────► G ──┐
     │                │ 0.1153
     P ◄──────────────┘
     ▲ │
0.9123│ │ 0.6068
     │ ▼
     └─ H
```

- 포스코에서 나가는 비중 합 = 0.0599 + 0.6068 = **0.6666** (≠1). 나머지 0.3334 는 포스코가
  **3노드 밖 다른 공급사**에서 매입 → 충격이 그쪽으로 **샌다(leakage)**.
- G·H 도 포스코로 0.1153 / 0.9123 만 되돌림(나머지는 자기 다른 거래처로 샘).

## 3. 충격 주입 — 0.1 at 포스코 (tariff = volume)

| 시나리오 | 입력 | 초기벡터 |
|---|---|---|
| 외생충격 tariff | `shock_rate = 0.1` (시드=P) | P=0.1, G=0, H=0 |
| 거래량변동 volume | `node_overrides=[{p1: P, delta: 0.1}]` | P=0.1, G=0, H=0 |

> 현재 설계(volume 0-기준·시드 직접 주입)에서 **둘의 초기벡터가 같다** → 같은 매입 에지로
> 전파하니 결과 동일. (옛 volume 의 거래처 `share×θ` 분배 방식은 폐기됨.)

## 4. 전파 풀이

`total = Σₖ Rᵏ · init` — 매입 에지를 한 홉씩 더 타고 가며 누적.

### 4-A. pin=True — 임펄스 (시드 고정)

포스코 incoming(G→P, H→P) 차단 → 포스코 0.1 고정, 바깥으로 한 번만.

| 회사 | 충격량 | 계산 | depth |
|---|---|---|---|
| P (포스코) | **0.10000** | 주입 고정 | 1 |
| H (합동) | **0.06068** | 0.1 × 0.6068 | 2 |
| G (지오) | **0.00599** | 0.1 × 0.0599 | 2 |

→ 각 공급사가 "포스코 매입에서 차지하는 비중"만큼 받음. 합동 60.7%, 지오 6%. (나머지 33%는
밖으로 새서 3노드엔 안 보임.)

### 4-B. pin=False — 일반균형 (순환, 자연 수렴)

시드를 고정 안 하면 충격이 G·H 를 거쳐 포스코로 되돌아와 순환. **이번엔 왕복배율이 1 미만**:

```
포스코 왕복배율 ρ = (P→G→P) + (P→H→P)
                 = 0.0599×0.1153 + 0.6068×0.9123
                 = 0.00690     + 0.55354
                 = 0.5604   (< 1 → damping 없이 수렴)
```

정상상태 방정식 (감쇠 불필요):
```
P = 0.1 + G·0.1153 + H·0.9123
G = P·0.0599
H = P·0.6068
→ P = 0.1 + P·(0.0599·0.1153 + 0.6068·0.9123) = 0.1 + 0.5604·P
```

```
P = 0.1 / (1 − 0.5604) = 0.1 / 0.4396 = 0.22750
G = 0.22750 × 0.0599  = 0.01362
H = 0.22750 × 0.6068  = 0.13804
```

**결과:**

| 회사 | 충격량 | (임펄스 대비) |
|---|---|---|
| P (포스코) | **0.22750** | 0.1 → 순환 되먹임으로 ~2.3배 |
| H (합동) | **0.13804** | 0.06068 → 증폭 |
| G (지오) | **0.01362** | 0.00599 → 증폭 |

> within-subgraph(3노드 한정)였다면 G·H 되돌림이 1.0 이라 ρ=1 발산 → 강제 damping 필요했지만,
> **연간 전체 기준에선 충격이 밖으로 새어 ρ=0.56<1**, 등비급수 `1/(1−0.56)≈2.27` 로 깔끔히 수렴.
