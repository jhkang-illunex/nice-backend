# 매입/매출 충격 전파 방향 점검 — 포스코·지오테크놀로지·합동씨티에스 (2026)

> 충격 전파 방향이 입력 데이터(`company_edge` 저장방향)와 일치하는지 점검한 결과.
> 예제는 포스코·지오테크놀로지·합동씨티에스 3노드, 2026 거래. 수치는 엔진(`nice_shock`) 검증.

## 0. 결론

**방향 정확함.** 매출충격 = 거래 **순방향**(시드의 고객으로), 매입충격 = 거래 **역방향**(시드의 공급사로).
순수 공급사(현대모비스)가 매입충격만 받고 매출충격엔 0 → 데이터·코드 일관성 입증(§7).

---

## 1. 데이터 저장 방향 정의

`company_edge` 한 행 = 한 거래:

| 컬럼 | 의미 |
|---|---|
| `from_bizno` | **셀러(공급)** bizno |
| `to_bizno` | **바이어(구매)** bizno |
| `sly_amt` | 공급가액(원) |

즉 **from → to = 셀러 → 바이어**(물건이 가는 방향). 근거: OpenAPI(`from`="셀러(거래 출발)",
`to`="바이어(거래 도착)"), 테스트셋 문서("저장방향 셀러 from → 바이어 to").

---

## 2. 방향 매핑 (검증됨)

| UI | API `direction` | 내부 | 전파 방향 | 저장방향 대비 | 영향 대상 |
|---|---|---|---|---|---|
| **매출충격** | `export` | downstream(0) | 셀러→바이어 | **그대로** | 시드의 **고객**(매출처) |
| **매입충격** | `import` | upstream(1) | 바이어→셀러 | **역방향(뒤집음)** | 시드의 **공급사**(매입처) |

> 매입만 거래의 반대 방향 — "사는 쪽 충격은 공급망 상류로 거슬러 올라간다(upstream)".

## 4. 매출 시 에지 (downstream)

방향 = **셀러→바이어**(저장방향 그대로). 가중치 = `거래액 / 셀러의 연간 Σ_out` (매출비중).

| 매출 에지 | 계산 | rate |
|---|---|---|
| 포스코 → 합동 | 1,092,315,642 / Σ_out(포스코) 1,200,072,233 | **0.9102** |
| 포스코 → 지오 | 107,756,591 / Σ_out(포스코) 1,200,072,233 | **0.0898** |
| 합동 → 포스코 | 1,092,315,642 / Σ_out(합동) 1,291,800,728 | 0.8456 |
| 지오 → 포스코 | 107,756,591 / Σ_out(지오) 481,350,011 | 0.2239 |

## 5. 매입 시 에지 (upstream)

방향 = **바이어→셀러**(저장방향 뒤집음). 가중치 = `거래액 / 바이어의 연간 Σ_in` (매입비중).

| 매입 에지 | 계산 | rate |
|---|---|---|
| 포스코 → 합동 | 1,092,315,642 / Σ_in(포스코) 1,800,180,187 | **0.6068** |
| 포스코 → 지오 | 107,756,591 / Σ_in(포스코) 1,800,180,187 | **0.0599** |
| 합동 → 포스코 | 1,092,315,642 / Σ_in(합동) 1,197,376,560 | 0.9123 |
| 지오 → 포스코 | 107,756,591 / Σ_in(지오) 934,580,732 | 0.1153 |

> 같은 거래라도 매출은 **셀러 Σ_out**, 매입은 **바이어 Σ_in** 으로 나눠 분모가 다르다.
> 그래서 포스코→합동이 매출 0.9102 / 매입 0.6068 로 값이 다르다.

## 6. 충격 계산식

**① 주입(init):** 시드에 충격량 주입. `init[시드] = shock_rate`, 나머지 0.

**② 전파:** 매입/매출 방향으로 정향된 가중치 행렬 R(위 §4/§5)로 무한 누적
```
shock = init + R·init + R²·init + … = Σₖ Rᵏ·init = (I − R)⁻¹·init   (ρ(R)<1 일 때 수렴)
```
= 직접(1홉) + 간접(2·3홉…) 합. (pin_seeds=False: 시드도 순환 되먹임 포함 — 일반균형. 확정값.)

**③ 정상상태 방정식 — 각 노드 = 주입 + 들어오는 에지로 받은 충격 합.**

### 매입(upstream) 예 — 포스코 충격 0.1
```
포스코 = 0.1 + 합동·0.9123 + 지오·0.1153   (합동→포스코, 지오→포스코)
합동   = 포스코·0.6068
지오   = 포스코·0.0599
```
대입: 포스코 = 0.1 + 포스코·(0.6068·0.9123 + 0.0599·0.1153) = 0.1 + 0.5604·포스코
```
포스코 = 0.1 / (1 − 0.5604) = 0.2275
합동   = 0.2275 · 0.6068 = 0.1380
지오   = 0.2275 · 0.0599 = 0.0136
```

### 매출(downstream) 예 — 포스코 충격 0.1
```
포스코 = 0.1 + 합동·0.8456 + 지오·0.2239
합동   = 포스코·0.9102
지오   = 포스코·0.0898
```
대입: 포스코 = 0.1 + 포스코·(0.9102·0.8456 + 0.0898·0.2239) = 0.1 + 0.7898·포스코
```
포스코 = 0.1 / (1 − 0.7898) = 0.4756
합동   = 0.4756 · 0.9102 = 0.4329
지오   = 0.4756 · 0.0898 = 0.0427
```

## 7. 충격 결과 (포스코 0.1, 2026, pin=False)

| 회사 | 매입충격 | 매출충격 |
|---|---|---|
| 포스코 | 0.22750 | 0.47563 |
| 합동씨티에스 | 0.13804 | 0.43292 |
| 지오테크놀로지 | 0.01362 | 0.04271 |

> 매출충격이 매입충격보다 큰 이유: 포스코↔합동 순환의 왕복배율이 매출(ρ=0.7898) > 매입(ρ=0.5604).
> 포스코 매출 중 합동 비중(0.9102)이 매입 중 합동 비중(0.6068)보다 커서.

## 8. 방향 검증 — 순수 공급사 (결정적 증거)

3노드(포스코·지오·합동)는 셋 다 양방향 거래라 매입·매출 양쪽에 다 나타나 구분이 안 된다.
포스코의 **순수 공급사**(포스코에 팔기만, 포스코→그회사 거래 없음)인 **현대모비스**로 검증:

| 노드 | 매입충격 | 매출충격 | 판정 |
|---|---|---|---|
| 현대모비스 (포스코 순수 공급사) | **0.07584** | **0** | ✅ 매입만 |

→ 현대모비스(현대모비스→포스코 만 존재)는 **매입충격에서만** 잡히고 매출충격엔 0.
"from=셀러/to=바이어 저장방향 → 매입=역방향 전파"가 데이터·코드에서 일관됨을 입증.
(포스코 + 직접거래처 depth-1 그래프 기준.)
